# Experiment 1: the published release rebuilt

The prerelease `v0.0.0-thesis.6` (commit `be5fc56e` on the branch `thesis/reproducible-builds`) was published by the release workflow on GitHub on 14 October 2026. We rebuilt it five times, from six days to six weeks after publication, and compared every output with the published files by SHA-256. The scripts are in [`scripts/5-release/local-vs-github-comparison/`](../scripts/5-release/local-vs-github-comparison/). Each rebuild has a dated note in Speciale2026, with its expectation written before the run, the commands verbatim and the results.

| Date | Machine | What was rebuilt | Result | Note |
| --- | --- | --- | --- | --- |
| 14 Oct 2026 | Linux x86-64 laptop (`arch`), alongside the release run | Every release asset: the frontend export (994 files), both Linux zips, both Windows zips, both migrators, the SQL script and `upgrade.sh`, plus the five container images | All identical. The Windows files matched once the release's 177 signatures were copied onto the rebuild (2130 files). A `SHA256SUMS` made from the rebuilt files equals the published one. The images' `linux/amd64` manifests equal the published ones | [2026-10-14-phoenix-reference-release](https://github.com/peterjuulm/Speciale2026/blob/main/notes/2026-10-14-phoenix-reference-release.md) |
| 20 Oct 2026 | The same laptop, after a reboot, with an empty NuGet cache | The same as on 14 October | All identical, the five image manifests included. The locked restore downloaded every package from nuget.org again. The frontend installed offline from the npm cache of 14 October | [2026-10-20-phoenix-delayed-rebuild](https://github.com/peterjuulm/Speciale2026/blob/main/notes/2026-10-20-phoenix-delayed-rebuild.md) |
| 21 Oct 2026 | An arm64 Mac (macOS), with an empty NuGet cache | The frontend export and the two Linux zips (WebAPI and job worker) | All identical: the 994 files of the export, the 1624 and 500 files in the zips, and both zips byte for byte | [2026-10-21-phoenix-mac-rebuild](https://github.com/peterjuulm/Speciale2026/blob/main/notes/2026-10-21-phoenix-mac-rebuild.md) |
| 23 Nov 2026 | A Mac Studio (macOS 26.4.1, arm64), empty NuGet and npm caches. The images built for `linux/amd64` in a Linux VM under Apple's emulator Rosetta | Every release asset and the five container images | All release files identical: the frontend export (994 files), all four zips (the Windows zips once the release's 177 signatures were pasted), both migrators, the SQL script, `upgrade.sh` and `SHA256SUMS`. Images: the job worker's manifest is GHCR's; `ws-pems` differs in one layer by Rosetta's empty cache folders ([E1-S6-07](findings.md#e1-s6-07), fixed on the branch since); the three MCP images differ only in the `apt-get` layer, Debian's security updates since 20 October ([E1-S6-05](findings.md#e1-s6-05), fixed after the tag) | [2026-11-23-phoenix-macstudio-rebuild](https://github.com/peterjuulm/Speciale2026/blob/main/notes/2026-11-23-phoenix-macstudio-rebuild.md) |
| 24 Nov 2026 | `arch` again, after a reboot, empty NuGet and npm caches | Every release asset and the five container images | All release files identical, the Windows files once the signatures were pasted. Images: the `ws-pems` and job worker manifests are GHCR's; the three MCP images differ only in the `apt-get` layer ([E1-S6-05](findings.md#e1-s6-05)). The Linux job's first restore failed on nuget.org time-outs and passed when run again | [2026-11-24-phoenix-arch-rebuild](https://github.com/peterjuulm/Speciale2026/blob/main/notes/2026-11-24-phoenix-arch-rebuild.md) |

Not covered: the Windows outputs were never built on Windows, only on Linux, as the release job builds them, and on macOS (23 November); the Mac of 21 October did not rebuild the Windows files, the migrators or the images; the October rebuilds fell within seven days of the release and the November ones five to six weeks after it.

The thesis's headline rebuild is a later prerelease, `v0.0.0-thesis.7`, built from the branch with every fix, E1-S6-05 and E1-S6-07 included. Its rebuilds will be added here.
